# Открывашка

Приложение для Android, которое открывает PDF, Word, Excel, презентации, фото, видео и текстовые файлы. Всё работает без интернета, файлы никуда не отправляются.

## Как установить

1. Откройте на телефоне страницу **Releases** этого репозитория (справа на главной странице) и скачайте `Otkryvashka.apk` из последнего релиза.
2. Откройте скачанный файл. Android попросит разрешить установку из этого источника (браузера или файлового менеджера): разрешите.
3. Нажмите «Установить».

Новая версия ставится поверх старой так же.

## Как пользоваться

- Нажмите «Выбрать файл» в приложении.
- Или в любом приложении (файлы, Telegram, почта) нажмите на файл → «Открыть с помощью» → «Открывашка». Через «Поделиться» тоже работает.

## Версия на Rust

В папке `rust/` лежит та же Открывашка на [Tauri](https://tauri.app): оболочка и работа с файлами написаны на Rust.

- Скачать: [Otkryvashka-Rust.apk](https://github.com/Parz1f/otkryvashka/releases/download/rust-latest/Otkryvashka-Rust.apk). В телефоне называется «Открывашка R» и ставится рядом с обычной.
- `rust/core` — библиотека без Android: распознаёт формат файла по содержимому (`detect.rs`) и читает текст документов Word 97–2003 по их внутренней таблице кусков (`doc.rs`). Тесты: `cd rust && cargo test -p otkryvashka-core`.
- `rust/src-tauri/src/lib.rs` — команды, которые вызывает страница: `detect_format`, `doc_text`, `incoming_info`, `take_incoming`, `quit`.
- `rust/src-tauri/gen/android` — Android-проект Tauri. `MainActivity.kt` копирует файл из «Открыть с помощью» в кэш, откуда его читает Rust.
- `.github/workflows/rust.yml` — сборка APK. Если она упадёт, лог окажется в ветке `ci-logs`.

## Как устроено

- `web/otkryvashka.html` — сам просмотрщик (веб-страница).
- `tools/build_www.py` — превращает её в стартовую страницу приложения (`app/src/main/assets/www/index.html`). Запускать после правок страницы.
- `app/src/main/assets/www/libs` — библиотеки просмотра: pdf.js, docx-preview, SheetJS, pptx-preview, JSZip.
- `app/src/main/java/.../MainActivity.java` — окно приложения: показывает страницу, выбор файлов, «Открыть с помощью» и кнопку «Назад».
- `.github/workflows/build.yml` — GitHub сам собирает APK при каждом изменении и выкладывает его в Releases.

Ключ подписи `app/otkryvashka.jks` лежит в репозитории, чтобы каждая сборка была подписана одинаково и обновления ставились поверх. Это подходит для личного приложения, но не для публикации в Google Play.
